# MoodMeal 🍝 - Feed Your Feelings

**A simple web app that gives you a recipe suggestion based on your mood.** 
Because nothing heals like food... especially when it's emotionally aligned.

---

## 🌐 Live Experience
> Start at **`index.html`** to use the app.

You’ll find a mood selector, a stylish toggle button to switch between light/dark mode, and a tasty experience waiting.

## 🔄 Navigation
- **Homepage (`index.html`)** – where you start, pick a mood, get fed.
- **Saved Recipes (`saved.html`)** – available from the footer link below. Here, you’ll see a list of the meals you saved, beautifully rendered in a table. If you didn’t save anything, it’ll make you feel guilty in a friendly way.
